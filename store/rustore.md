# Материалы для карточки в RuStore

Файл-заготовка: тексты отсюда вставляются в консоль разработчика.

## Название

```
Галка: Планы и заметки
```

## Краткое описание

```
Ежедневник с напоминаниями. Задачи на любые дни, разделы, всё офлайн.
```

## Полное описание

```
«Галка» — простой ежедневник для тех, у кого много дел сразу в нескольких
направлениях. Записал, не забыл, сделал, поставил галочку.

КАЛЕНДАРЬ
Месяц целиком с цветными метками занятых дней. Тап по заголовку — переход
к любому месяцу и году. Под календарём лента дел выбранного дня: сначала
задачи со временем, отдельно те, у которых времени нет. Календарь можно
свернуть до одной недели, между вкладками — свайп.

ЗАДАЧИ НА СКОЛЬКО УГОДНО ДНЕЙ
У задачи не одна дата, а набор дней. Нужно на один день — отметь один.
Нужно две недели подряд, каждую неделю или свой набор — отметь пальцем
прямо на календаре внутри задачи. Каждый день закрывается отдельно, видно
прогресс: 3 из 7.

РАЗДЕЛЫ
Раздел — папка со своим цветом и описанием. Внутри «Учёбы» спокойно живут
несколько циклов, внутри работы — свои дела. Список задач показывается
по разделам или подряд по датам, с фильтром по разделам.

НАПОМИНАНИЯ
Четыре вида, каждый включается отдельно и в своё время:
• напоминание перед задачей со временем;
• список всех дел на сегодня утром;
• отдельное напоминание о задачах без указанного времени;
• вечерняя сводка того, что осталось незакрытым.

БЕЗ ИНТЕРНЕТА И БЕЗ АККАУНТОВ
Регистрации нет. Данные хранятся на телефоне и никуда не отправляются.
Рекламы, аналитики и слежки нет. Приложение бесплатное.

ПЕРЕНОС ДАННЫХ
Задачи сохраняются в файл и читаются из него обратно — для резервной копии
или переезда на другой телефон. Файл открывается прямо из проводника.
При загрузке можно добавить к имеющимся записям или заменить их целиком.
Перед удалением всех данных приложение само сохраняет копию в «Загрузки».

ОФОРМЛЕНИЕ
Тёмная и светлая темы, семь цветов оформления. Свои окна выбора времени,
даты и вариантов вместо системных — приложение выглядит одинаково на любом
телефоне.
```

## Если модерация спросит про разрешения

**Точные будильники (USE_EXACT_ALARM, SCHEDULE_EXACT_ALARM).** Приложение —
планировщик с напоминаниями, а это прямо тот случай, для которого разрешение
предназначено. Без него Android сдвигает срабатывание ради экономии батареи,
и напоминание «в 14:30» приходит с опозданием, теряя смысл.

**Доступ в интернет.** Используется только для проверки обновлений в сборке,
раздаваемой файлом. В магазинной сборке этот раздел скрыт: `DISTRIBUTION`
в `www/app.js` переключается на `'store'`.

## Что нужно приложить, кроме текстов

- **APK** — собранный релиз, подписанный своим ключом;
- **иконка** — `store/icon-512.png`, собирается `node store/make-icons.js`;
- **скриншоты** — не меньше двух, с реального устройства.

Для скриншотов есть готовый набор данных: `store/demo.galka`. Даты в нём
считаются от дня выгрузки, поэтому календарь не будет пустым. Поставить —
Настройки → Импорт → «Заменить всё». Пересобрать набор: `node store/make-demo.js`.

Полезно снять четыре экрана: календарь с делами на день, задачи по разделам
с раскрытой многодневной задачей, редактор задачи с выбором дней, настройки.

## Перед сборкой для магазина

1. В `www/app.js` поставить `const DISTRIBUTION = 'store';`
2. `npx cap sync android`
3. `cd android; .\gradlew.bat assembleRelease`
4. После сборки вернуть `'github'`, иначе в версии для файловой раздачи
   пропадёт проверка обновлений.
